4.2 Téléchargement du logiciel
------------------------------

Lorsque nous recevons la carte de contrôle, nous devons d'abord télécharger l'IDE Arduino et le pilote.

Vous pouvez télécharger l'IDE Arduino depuis le site officiel :
https://www.arduino.cc/en/software.

Il existe différentes versions pour Arduino, téléchargez simplement une version adaptée à votre système. Nous prendrons le système WINDOWS comme exemple pour vous montrer comment le télécharger et l'installer.

|image1|

Il vous suffit de cliquer sur JUSTDOWNLOAD, puis de cliquer sur le fichier téléchargé pour l'installer.

Et lorsque le fichier ZIP est téléchargé, vous pouvez le décompresser directement et le lancer.

4.4 Ajouter une bibliothèque
----------------------------

Que sont les bibliothèques ?

Les bibliothèques sont des ensembles de codes qui vous permettent de vous connecter facilement à un capteur, un écran, un module, etc.

Des centaines de bibliothèques supplémentaires sont disponibles sur Internet pour le téléchargement.
