4.2 Download del Software
-------------------------

Una volta ricevuta la scheda di controllo, è necessario scaricare innanzitutto l'IDE di Arduino e i driver.

Puoi scaricare l'IDE di Arduino dal sito ufficiale:
https://www.arduino.cc/en/software.

Esistono varie versioni per Arduino, scarica semplicemente la versione adatta al tuo sistema; prenderemo il sistema WINDOWS come esempio per mostrarti come scaricare e installare il programma.

|image1|

Devi solo cliccare su JUSTDOWNLOAD, quindi fare clic sul file scaricato per installarlo.

Inoltre, quando il file ZIP è stato scaricato, puoi decomprimerlo e avviarlo direttamente.
