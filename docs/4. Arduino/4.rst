4.2 Descarga de software
------------------------

Cuando tengamos la placa de control, primero necesitamos descargar el IDE de Arduino y el controlador.

Puedes descargar el IDE de Arduino desde el sitio web oficial:
https://www.arduino.cc/en/software.

Hay varias versiones para Arduino, simplemente descarga una versión adecuada para tu sistema; tomaremos el sistema WINDOWS como ejemplo para mostrarte cómo descargar e instalar.

|image1|

Solo necesitas hacer clic en JUSTDOWNLOAD, luego haz clic en el archivo descargado para instalarlo.

Y cuando se descargue el archivo ZIP, puedes descomprimirlo y ejecutarlo directamente.
